Privacy Policy

Polymarket Dataset Archive is a personal tool operated by its owner for their own research. It has no other users.

Data accessed

The application requests the Google Drive scope drive.file only. It can read and write only the files and folders that it created itself in the owner's Google Drive. It does not access any other Drive content, contacts, e-mail or personal profile data.

Data stored

The files it writes are datasets of public market data from Polymarket. They contain no personal data. The OAuth refresh token is stored on the owner's private server and is never shared.

Sharing

No data is sold, shared with or transferred to third parties. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and deletion

Questions or requests: open an issue at the repository linked from the homepage, or write to the developer contact e-mail listed in the Google Cloud project. Access can be revoked at any time at myaccount.google.com/permissions.
